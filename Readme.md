## Cómo ejecutar
Desde la carpeta del proyecto, instalar las dependencias:

npm install

Luego, ejecutar el proyecto utilizando el script correspondiente definido en package.json.

Por ejemplo:

npm run <script>

Las pruebas y ejercicios se encuentran organizados en sus respectivas carpetas.
